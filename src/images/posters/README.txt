Posters for each edition go here, named after the edition year, followed by
a two-digit number:

  1949-01.jpg → the poster shown on editions.html for EXPRMNTL 1
  1949-02.jpg → an alternate/second poster design for the same edition

WHAT HAPPENS AUTOMATICALLY, based on how many numbered files you add:

- Just "-01.jpg": shown as the poster, same as today. No change in behaviour.
- Add "-02.jpg" and onward too: the poster becomes clickable, with a small
  "N versions" hint in the corner — clicking opens a gallery lightbox to
  browse all the numbered poster designs you've added, in order.

No HTML editing needed either way. Always start at -01 with no gaps
(01, 02, 03…) — the site stops looking as soon as a number is missing.

The "Photographs" resource in each edition's list works the same way, but
lives in images/editions/{year}-01.jpg, -02.jpg, etc. — see the README in
that folder for details.
