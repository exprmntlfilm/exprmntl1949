Photos for each edition's general gallery go here (crowd shots, venue,
press days — anything not tied to one specific film or person), named after
the edition year, followed by a two-digit number:

  1949-01.jpg → first photo for the 1949 edition
  1949-02.jpg → second photo for the same edition
  1958-01.jpg → first photo for the 1958 edition

To find which section a photo belongs to, check the year heading on
editions.html (EXPRMNTL 1 — 1949, EXPRMNTL 2 — 1958, and so on).

WHAT HAPPENS AUTOMATICALLY, based on how many numbered files you add:

- Add just "-01.jpg": nothing changes yet — the "Photographs" row in that
  edition's Resources list still needs a 2nd photo to activate (see below).
- Add "-02.jpg" and onward too: the "Photographs" row turns into a
  "View Gallery" button on its own, opening a lightbox with all the
  numbered photos you've added, in order.

No HTML editing needed either way, and you only ever upload each file once.
Always start at -01 with no gaps (01, 02, 03…) — the site stops looking as
soon as a number is missing.

This is the same system used for film stills (images/stills/), director
portraits (images/portraits/), and edition posters (images/posters/) — see
the README in each of those folders for details specific to them.

Recommended format: .jpg, roughly 1200px on the longest side is plenty for
the web (no need to upload full-resolution scans here — keep those in your
own archive).
